# Exa (exa.ai) — State of Play, October 2026

**Report date:** 2026-10-19 · **Task:** AT-TH6H · **Method:** live sources via curl/gh — vendor primary sources (exa.ai blog, docs, llms.txt, sitemap), HN Algolia threads, Nebius newsroom, Perplexity/Brave pricing pages, GitHub API. Every claim date-stamped; vendor self-claims flagged as such.

---

## TL;DR

Exa has moved from "web search API for AI apps" (2023–2025) to **agent-native knowledge platform**: a self-built index plus structured vertical libraries, an agentic research product tier, third-party data federation (Exa Connect), and distribution baked into browsers, Gemini, OpenRouter, and every major agent client. It raised $85M (Sep 2025, $700M val) then **$250M Series C at a $2.2B valuation led by a16z (May 20, 2026)**, landed **Firefox** (Aug 2026) and **Google Gemini Enterprise grounding** (Apr 2026) as flagship distribution, and shipped **Exa 3.0 literally today (Oct 19, 2026)** with a new $4/1k low-cost tier. Its closest startup rival Tavily was **acquired by Nebius (announced Feb 10, 2026)**, consolidating the field. Main open questions: pricing pressure from Perplexity ($1–2.50/1k) and LLM-native search, and the fact that nearly all Exa quality claims are vendor-run evals on vendor-adjacent benchmarks.

## 2. Product surface today (verified 2026-10-19 via exa.ai/docs/llms.txt)

**Core APIs** (pay-as-you-go, no subscription, no minimum; free tier $10/mo ≈ 2,500 Lite searches + one-time $10 onboarding bonus):

- **Search API** — tiers: **Lite $4/1k** (new today, same index as Auto), Instant $4/1k (sub-200ms), Fast/Auto $7/1k; Deep Search $12–15/1k; +$1/1k results above 10. (docs/admin/pricing.md, 2026-10-19)
- **Contents API** — $1/1k pages, JS-rendered pages, PDFs; **Dynamic Highlights GA** at no extra charge with Exa 3.0 (2026-10-19).
- **Answer** — $5/1k, LLM answer w/ citations.
- **Exa Agent** — async multi-step research/list-building/enrichment, $0.012–$1.00 fixed-effort runs; **Agent Ultra** top tier (2026-09-25).
- **Deep Max** — contact-sales premium agentic search (2026-04-20).
- **Monitors API** — $15/1k, scheduled searches → webhooks of only-new results.
- **Batch API**, **Snapshot** (pin search/contents to a stored page version), **OpenAI SDK drop-in compatibility**.
- **Websets** (the May-2025 Launch HN product) — still alive with separate credit system and dashboard, but docs now steer new list-building work to Exa Agent; reads as legacy-maintenance mode (docs/websets/quickstart.md, 2026-10-19).

**Exa Library** (structured vertical collections searchable via the standard search call): people, companies, job postings, SEC filings, earnings calls, stock pages/market quotes, research papers, patents, court opinions, podcasts, Wikipedia, products, events, **places (211M, 2026-10-05)**, weather, sports, indicators, countries. With Exa 3.0: 1.27B ecommerce listings with prices/availability, real-time news/sports/weather/markets, flights, transit (2026-10-19).

**Exa Connect** (data federation): premium third-party providers inside Agent runs — Fiber.ai (B2B), Similarweb, Baselayer (KYB), Polymarket, Macrobond, Financial Datasets (27k+ US tickers), Particle (podcasts), Jinko (flights/hotels), Affiliate.com, plus contact-sales partners. This is Exa positioning as the *broker* between agents and the paid-data economy, not just a crawler.

**Agent-native surfaces:** hosted MCP server at mcp.exa.ai (usable without an API key at low volume), installable Agent Skills (`npx skills add exa-labs/agent-skills`), exa-code (coding-agent context, 2025-09-25), integrations: ChatGPT/Codex, Claude (Code/Web/Desktop, incl. enterprise-managed auth via Okta XAA), Cursor, Slack app, Google Sheets, Grok Build marketplace, Vercel AI Gateway + fx, n8n, Snowflake, LangChain/LlamaIndex/Pydantic AI/CrewAI, ElevenLabs voice, OpenRouter (`openrouter:web_search` server tool), Baseten hosted tools.

**Payments oddity worth noting:** keyless per-request payment via x402 (USDC on Base/Arc/World Chain/Solana, Circle nanopayments), Tempo MPP, Nevermined, and **free access for World AgentKit-verified agents** — an explicit bet on machine-to-machine commerce (docs, 2026-10-19).

**Enterprise posture:** HIPAA mode (eligible cached retrieval), Zero Data Retention (the Firefox deal's key term), Singapore region (2026-03-30), status page, SOC-style trust center.

## 3. The strategy shift, narrated

1. **2023–2024:** generic web search API for AI apps ("first web search API for AI," per founder). Own index + custom embeddings as the moat claim vs SERP scrapers.
2. **2025:** verticalize quality (people/companies/code/papers) + Websets for GTM list-building; Series B on that story. Microsoft's Bing-data cutoff to third parties (Wired, 2025-05-14, via Exa's own blog links) squeezed SERP-wrapper competitors — a structural tailwind Exa explicitly markets against ("wrappers cannot compete on quality/latency/cost," Series C post, 2026-05-20).
3. **2026:** three moves at once —
   - **Latency/cost ladder** (Instant Feb → Lite Oct): own the Pareto frontier from voice-app sub-200ms to exhaustion research.
   - **Agentic research products** (Deep Max Apr, Agent Ultra Sep): compete with Perplexity/You.com/Parallel *and* with frontier labs' native search.
   - **Data platform** (Library verticals, Connect federation, Places, ecommerce): become the schema layer agents query — closer to "Bloomberg-for-agents" than "Google-for-AI."

## 5. Claims & evals — read with the skepticism they deserve

- **All headline quality claims are vendor-run.** "Ranks first on every benchmark we tested" (Exa 3.0, 2026-10-19); "Exa defines the cost-performance Pareto frontier… 16% across search backends" (ATLAS, 2026-10-08); Agent Ultra beats everyone (2026-09-25). No independent replication found in HN discourse; ATLAS launched 11 days before the 3.0 "first on every benchmark" claim, and Exa grades its own ATLAS runs.
- **ATLAS itself (2026-10-08) is the most substantive artifact:** 547 tasks generated from clustered real search demand; claims only 9% memorization vs BrowseComp 48% / WideSearch 59% / DeepSearchQA 61% (memorization probed with GPT-6 Astra, GPT-5.6 Sol, Claude Opus 5); $2 grading cost vs WANDR's $18k–50k. Its honest finding — **no agent under $1/task reaches row-F1 > 0.5, and even max-effort agents miss ~1/3 of golden results** — is more credible than the marketing around it, and doubles as Exa's sales pitch for exhaustive search.
- **Latency claim** (sub-200ms, 15× faster than rivals, 2026-02-12) is vendor-benchmarked from us-west-1 with SealQA-derived queries; plausible directionally, unverified independently.
- **Index size** is slippery marketing: "tracks 2T URLs" ≠ serves 2T; the served figure is 100B pages (FAQ, Oct 2026).

## 6. Criticism & practitioner sentiment (dated)

- **Crawler ethics:** "Do you respect robots.txt?" asked directly in Launch HN (user xena, 2025-05-06) — no founder answer surfaced in the thread. A Twitter user accused Exa of "indexing personal site data ignoring robots.txt" (2026-01-11, HN submission; tweet itself not loadable — unverified). Current official posture (FAQ, Oct 2026): ExaSearchBot respects robots.txt, rate-limits, no paywall/CAPTCHA/login bypass, `noindex` honored on next re-fetch, verification at crawler.exa.ai. LinkedIn-derived people data was called out as ToS-ironic in Launch HN (2025-05-06).
- **Websets pricing sticker shock:** one complex search with 2 free enrichment columns ate 750 of 1,000 free credits; $49 tier ≈ 10 searches/mo (user vetleen, 2025-05-06). Websets remains a separate-credit product; Exa has since pushed the use case to pay-as-you-go Agent.
- **Result-quality misses:** e-commerce constraint queries failed badly in Websets demos (theamk's servo-motor test, mdaniel's 30/70 hit-rate GitHub-repo test, 2025-05-06). Counterweight: unprompted positive anecdotes vs Google for recent dev content (gigatexal, Series B thread, 2025-09-03). Exa 3.0's ecommerce index expansion (1.27B listings, 2026-10-19) is presumably the response to exactly this weakness class.
- **Pricing-page confusion:** acknowledged by Exa staff in HN ("Yeah this has evolved to be confusing," jldadriano, 2025-09-03). The Lite/Instant/Fast/Auto ladder adds another axis.
- **Founder posture:** willbryk engaged heavily and candidly in threads (2025); hired CRO signals enterprise GTM maturation (2026-05-20).
- **Napkin-math critique** (kshivendu.dev, 2025-09-16, updated Oct 2026): reverse-engineers Exa infra from its own engineering blogs (BM25 in RAM with 50% savings via fp8 postings; binary-quantized Matryoshka embeddings, 4096→256 dims; IVF index; S3-backed exa-d). Conclusion is cost-plausibility, not scandal — but it's the best public independent technical read on how Exa actually works.

## 8. What to watch next

1. **Independent evals of Exa 3.0 / Lite** — the entire current quality story is vendor-run; ATLAS adoption by third parties would be the tell.
2. **Perplexity + Nebius-Tavily price war at the $1–2.5/1k bottom** vs Exa defending $4–7 with quality claims; Lite ($4) is the first direct counter.
3. **Whether the labs' native search (OpenAI/Anthropic/Google) keeps absorbing the "good enough" tier** — Exa's own benchmarks now frame the labs as rivals; but Gemini Enterprise *also* distributes Exa (2026-04-28), so it's co-opetition.
4. **Connect/Library monetization** — if agent data federation works, Exa's TAM stops looking like "search API" and starts looking like "data brokerage for agents."
5. **Crawler politics** — robots.txt accusations + a 2T-URL crawler + people/company verticals is a growing regulatory/reputational surface (EU AI Act transparency, copyright suits against AI crawlers generally; nothing Exa-specific found live this session).
